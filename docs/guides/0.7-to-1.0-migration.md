# 0.7 → 1.0 迁移指南(初稿)

> **状态**:初稿(spec:82「公共 API 冻结候选;迁移指南初稿」,P2 出口物)。范围:API 改名 + 项目状态格式兼容。完整的发布版指南(含存储迁移器,若届时补)+ CHANGELOG 归 P4(spec:94)。P4 发布时本指南应译为英文,与 CHANGELOG 一并发布。

## 概述

1.0 是一个破坏性(braking)版本:公共 API 做了一次性清理——移除全部 `__experimental_*` 前缀与 `studio.__experimental` 命名空间;同时**项目状态文件格式保持向后兼容**。从 0.7.x 升级,通常只需处理两件事:

1. 按 §1 的映射表把代码里的旧 API 名换成新名。
2. 0.7 的项目状态 JSON(见 §2)可直接打开,**不需要**任何格式迁移。

## 1. API 改名映射

以下 10 项在 1.0 中全部转正/合并(来源:Task A1 处置矩阵)。`旧写法 → 新写法` 一一对应。

| # | 旧 API | 新 API |
|---|---|---|
| 1 | `sheet.sequence.__experimental_getKeyframes(...)` | `sheet.sequence.getKeyframes(...)` |
| 2 | `sheet.__experimental_forgetObject(obj)` | `sheet.forgetObject(obj)` |
| 3 | `sheet.__experimental_forgetSheet(sheet)` | `sheet.forgetSheet(sheet)` |
| 4 | `sheet.__experimental_sequenceProp(pointer)` | `sheet.sequenceProp(pointer)` |
| 5 | `init({__experimental_rafDriver})` | `init({rafDriver})` |
| 6 | `studio.extend(ext, {__experimental_reconfigure: true})` | `studio.extend(ext, {reconfigure: true})` |
| 7 | `studio.__experimental.__experimental_disablePlayPauseKeyboardShortcut()` | `studio.disablePlayPauseKeyboardShortcut()` |
| 8 | `studio.__experimental.__experimental_enablePlayPauseKeyboardShortcut()` | `studio.enablePlayPauseKeyboardShortcut()` |
| 9 | `studio.__experimental.__experimental_clearPersistentStorage()` | `studio.clearPersistentStorage(persistenceKey?)` |
| 10 | `studio.__experimental.__experimental_createContentOfSaveFileTyped(id)` | `studio.createContentOfSaveFile(id)`(并入,返回类型定稿为 `OnDiskState`) |

### 1.1 关键帧读取

```ts
// 0.7
const keyframes = sheet.sequence.__experimental_getKeyframes(obj.pointer.x)

// 1.0
const keyframes = sheet.sequence.getKeyframes(obj.pointer.x) // BasicKeyframe[]
```

### 1.2 对象 / sheet 管理

```ts
// 0.7
sheet.__experimental_forgetObject(myObject)
sheet.__experimental_forgetSheet(anotherSheet)
sheet.__experimental_sequenceProp(propPointer)

// 1.0
sheet.forgetObject(myObject)
sheet.forgetSheet(anotherSheet)
sheet.sequenceProp<V>(propPointer)
```

### 1.3 启动配置

```ts
// 0.7
init({__experimental_rafDriver: myRafDriver})

// 1.0
init({rafDriver: myRafDriver}) // IRafDriver,与 IProjectConfig.rafDriver 同名一致
```

### 1.4 扩展重配置

```ts
// 0.7
studio.extend(myExtension, {__experimental_reconfigure: true})

// 1.0
studio.extend(myExtension, {reconfigure: true})
```

### 1.5 键盘快捷键

```ts
// 0.7
studio.__experimental.__experimental_disablePlayPauseKeyboardShortcut()
studio.__experimental.__experimental_enablePlayPauseKeyboardShortcut()

// 1.0
studio.disablePlayPauseKeyboardShortcut()
studio.enablePlayPauseKeyboardShortcut()
```

### 1.6 清空持久化数据

```ts
// 0.7
studio.__experimental.__experimental_clearPersistentStorage()

// 1.0
studio.clearPersistentStorage()              // 清空当前 key
studio.clearPersistentStorage('custom-key')  // 指定 key(可空参)
```

### 1.7 导出项目状态

```ts
// 0.7
const state = studio.__experimental.__experimental_createContentOfSaveFileTyped('Sample project')

// 1.0 —— 与 0.7 的 createContentOfSaveFile 合并,返回强类型 OnDiskState
const state: OnDiskState = studio.createContentOfSaveFile('Sample project')
```

> 注意:10 项之外,`__experimental_syncServer`(仅 playground 演示用)不属于公共 API,无迁移动作。

## 2. 项目状态格式兼容

- 0.7 的项目状态 JSON(即 `createContentOfSaveFile` 的产物)在 1.0 中可直接打开,**格式未变**:

```ts
import {getProject} from '@toy-box/core'

const project = getProject('Sample project', {
  state: myOnDiskState, // 0.7 导出 / 或手工按形状构造
})
```

- 状态顶层形状与 `definitionVersion: '0.4.0'` **与 0.7 相同**,未升级。`getProject` 会对 `config.state` 做浅校验(`definitionVersion` 匹配;未来版本号会被拒绝)。
- 格式兼容链由回归测试钉死:仓库内置 0.7 代表性 fixture(关键帧、compound props、assets),覆盖「导入 → 导出 round-trip」与「未来版本拒绝」两条路径。升级不影响该承诺。
- 若 0.7 中通过 `studio.transaction()` 手动构造状态,1.0 行为不变(乐观更新、undo、持久化语义一致)。

## 3. 存储介质说明(localStorage → IndexedDB)

- **0.7**:项目数据存 localStorage(key `theatrejs:0.4`)。
- **1.0**:项目数据存 **IndexedDB**(单人模式 = 进程内 SaazBack,前后端分别经 `BackIDBAdapter` / `FrontIDBAdapter` 落库)。
- **当前版本不提供 localStorage → IndexedDB 自动迁移**:系统未对外发布、无 0.7 存量用户,不值得为一次性升级引入迁移器。**升级后原 localStorage 数据保留不动(只读不删)**。
- 若要手动保留 0.7 数据:从 localStorage 取出原 blob → 作为 `config.state` 注入 `getProject(id, {state})` 即可回填(格式兼容见 §2)。
- 若 1.0 正式发布需要承接上游 0.7.x 用户,按 spec:149-156 补一次性迁移器(首次启动检测 localStorage 0.7 blob → 校验/迁移 → 作为初始快照写入 IDB;失败时旧数据保留、UI 提示手动导出恢复)。本指南届时更新。

## 4. `init()` / `getProject()` 行为说明

- `init(opts?)` 行为与 0.7 一致:**幂等**,只有首次调用生效;`rafDriver` 选项见 §1.3。
- `getProject(id, config?)` 行为与 0.7 一致;`config.state` 经过浅校验(`shallowValidateOnDiskState`)。
- 持久化健壮性(1.0 新增):IndexedDB 不可用(隐私模式/quota 满)时,自动降级为内存存储,**编辑永远可用**;studio 内出现提示条「This session's state won't be saved.」,不崩溃不阻塞。
