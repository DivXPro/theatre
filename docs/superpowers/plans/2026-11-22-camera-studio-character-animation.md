# Camera Studio 角色动画三步实施计划

**目标**　在同一个场景里设置角色静态姿势、保留属性关键帧、编排和编辑动作片段，并
让角色沿可编辑的路径移动。

**设计确认**　先确认 Mock 中的保存目标、轨道布局、动作局部时间和路径绑定。确认后
按以下顺序实施。每一步在真实项目里用相应流程验收。

**技术范围**　沿用 Theatre Studio 时间轴和事务、Camera Studio 的模型与动作片
段、Three.js 骨骼和路径采样、现有导出入口。现有工程和资产继续可读。

基于
[动作拍摄时间轴 V1](../specs/2026-11-21-camera-studio-animation-strips-design.md)
和 [动作轨 V2 草案](../specs/2026-11-22-camera-studio-action-tracks-design.md)，
补充骨骼动作编辑、循环和角色路径。V2 草案里的双动作交叉过渡仍作为单独增量。

## 姿势保存到哪里

| 操作                                     | 保存结果                         | 播放时的效果                                                             |
| ---------------------------------------- | -------------------------------- | ------------------------------------------------------------------------ |
| 选角色 → 编辑静态姿势 → 保存静态姿势     | 角色的默认整身姿势               | 任意场景时间均可作为基础。没有动画控制的骨骼保留该姿势                   |
| 时间轴 → 场景姿势 `◇/◆` → 写入当前场景帧 | 场景 `姿势` 属性轨道上的整身快照 | 按场景时间采样，在相同骨骼通道上覆盖动作片段。首尾帧外默认保持最近的姿势 |
| 选片段 → 编辑动作 → 记录关键帧 → 应用    | 动作内部的骨骼关键帧             | 按动作局部时间采样。同一动作的各次循环使用相同的修改                     |

三种入口复用同一组视口控制器。右栏显示当前保存目标。静态编辑单独预览角色的基础姿
势，保存后恢复场景合成。已有动画覆盖相关骨骼时提示「当前帧由动画驱动」。三种编辑
都可取消，成功提交各自对应一次撤销。

## 场景姿势如何覆盖动作

- **场景姿势默认参照 Blender 活动动作的替换和保持规则。** 有有效姿势关键帧时，场
  景姿势以 100% 权重替换低层动作提供的同一骨骼通道。帧与帧之间沿用现有姿势插值，
  首帧之前保持首帧，末帧之后保持末帧。没有姿势关键帧时，骨骼动作继续播放，空档使
  用角色的默认姿势。已有姿势轨沿用原播放行为。
- **只有一颗整身姿势关键帧时，首尾就是同一颗。** 例如第 1–100 帧有走路动作，第
  33 帧写入一个全身姿势，走路片段在这段时间的骨骼表现都会被第 33 帧的姿势取代。
  位置轨道和路径继续驱动角色移动。要修一拍走路姿势或让每个循环重复同样的修正，从
  动作片段进入局部时间编辑。
- **时间轴提示生效范围。** 「姿势 · 场景」仍是一条整身姿势属性轨。用实线显示首尾
  关键帧之间的范围，两端用虚线显示保持范围。右栏区分关键帧、帧间插值和端点保持，
  首次写入前说明即将覆盖骨骼动作。右栏的 `◇/◆` 继续表示当前帧是否存有关键帧。

## 属性面板与动作轨的分工

- **角色属性只保留「默认姿势」。** 它显示当前的预设名或「自定义」，沿用现有预设
  选择器，旁边提供「编辑」。换预设或保存静态摆姿势都只更新角色的默认值。
- **「场景姿势」只在时间轴出现。** 时间轴行显示当前场景帧，空心 `◇` 表示可新增，
  实心 `◆` 表示可更新。点菱形或时间轴上的姿势关键帧，进入同一个摆姿势视图。新帧
  以当前画面姿势起手，保存时只写该帧，首次保存时创建姿势属性轨。右栏显示场景姿势
  已经覆盖动作片段的状态。
- **动作编排**通过时间轴角色行的 `＋` 菜单和轨道行的「＋ 添加片段」进入。`＋` 只
  占 22px，点开后选择「骨骼动作轨」或「变换轨」，避免选项文字挤占角色名称。选择
  片段后，右栏才显示该片段的来源、时间范围及「编辑动作」。角色属性页移除常驻的
  「动作」选择器，原来的资产选择体验放到添加片段流程。此项替代 V2 草案中从对象属
  性建轨的入口。
- **旧工程**继续保存、读取原 `animation` 字段。只使用旧版动作的角色在时间轴显示
  「旧版动作」入口，沿用其播放和选择设置。创建空动作轨或加入对象变换片段时继续使
  用旧版骨骼播放；加入首个骨骼片段后由动作轨接管，移除最后一个骨骼片段后恢复旧版
  播放。加载工程时保留原动作时序。

## 每一步的保存与导出验收

- [ ] 使用同一个 30 fps 验收工程，依次加入静态姿势与属性轨、五次走路循环、直线与
      圆弧路径。单独保留姿势覆盖的验证场景，让走路场景能观察循环内的骨骼变化。每
      一步都保存、关闭并重开，再在相同场景帧对照拖动播放头、正常播放和视频导出。
      用一份已有动作与姿势轨的旧工程检查加载和再次保存后的结果。
- [ ] 参考 Blender 按场景帧读取动画与约束求值后的结果。从第一步起，预览、播放和
      `videoExport/previsExporter.ts` 逐帧导出共用场景时间求值。先采样属性、片
      段、姿势和已生效的路径，再更新角色世界矩阵，供相机跟随和渲染使用。验收比较
      同一时刻的世界位置、朝向和代表性骨骼变换。按帧号解码短视频抽查画面，数值对
      照以编码前的场景状态为准。

## 第一步　静态姿势、属性轨道与动作编排

- [ ] 模型下保留现有属性轨道，显示多条动作轨。场景播放头和吸附网格供两类轨道共
      用。选中属性关键帧时右栏显示属性值，选中片段时显示动作来源、场景起点和动作
      入出点。
- [ ] 角色属性只保留「默认姿势」一行；`pose` 属性配置为详情面板隐藏，场景姿势只
      在时间轴行和关键帧弹框中出现。复用 `PosePropEditor.tsx` 的预设选择器和
      `PoseModeRig.tsx` 的视口交互，按入口选择写入目标。角色静态姿势存入单独的静
      态字段。旧工程中未建轨的 `pose` 值在没有单独静态姿势时继续作为基础。第一次
      把旧静态 `pose` 转成场景轨时，在同一事务内留存其基础值。保留已建的 `pose`
      和手势轨道。
- [ ] 扩展 `animationTracks` 文档，保留 `轨道 → 片段 → 动作` 的引用关系。读取 V1
      后保留原有 ID、时间和资产引用，首次成功编辑时再写入新版。复用
      `animationStrips` 和 Studio 的 `additionalRows`，支持从时间轴新增轨、添加
      片段、拖动、裁剪、换轨及撤销。将旧版动作的入口放入相同时间轴。
- [ ] 跑通对象动作的局部关键帧编辑。可手动编辑位置、旋转和缩放，场景属性继续支持
      逐分量打点。播放时用原有属性值作为底层，活动的对象动作覆盖自己的变换组。不
      同轨道的不同通道可以并行，同组重叠在提交前报出冲突区间。片段外恢复属性轨的
      采样值。
- [ ] 将根变换与骨骼采样接到同一个按场景时间求值的入口。骨骼按绑定姿势、角色静态
      姿势、骨骼动作片段、场景姿势、手势的顺序覆盖，各层只写自己的通道。按当前帧
      读取 Theatre 属性，应用模型世界变换后再供相机跟随和渲染读取。把旧工程重开
      及导出的一致性作为回归门槛。

**Mock 确认点**　点视口里的「白模角色」，先在「默认姿势」选预设或手动保存，再在
时间轴点「场景姿势」的空心菱形。后者新增姿势轨和关键帧。点时间轴里的「＋ 动作
轨」，在空轨添加「入场位移」，核对右栏是否清楚地跟随角色、轨道或片段切换。

**验收**　保存静态姿势并重开工程，确认任意场景帧保留该姿势，时间轴无新增关键帧。
加走路片段后检查动作区间内的摆臂和空档的静态姿势。只在第 33 帧写入整身姿势，核对
前后帧都保持该姿势，位置轨仍在求值，撤销后恢复走路。写入两颗不同姿势，核对中间插
值和首尾保持。用旧工程验证既有覆盖顺序。检查对象变换与骨骼动作并行、同组冲突提
示、拖动裁剪和撤销重做。选静态空档、片段边界和第 33 帧执行保存重开与导出验收。

## 第二步　手动编辑骨骼动作与循环

- [x] 参考 Blender NLA 的 Tweak Mode，从片段双击或右栏「编辑动作」进入。底部切换
      到动作局部时间，进入时复用播放采用的场景时间到动作时间映射，落在当前循环的
      对应局部帧。片段之前定位到动作入点，片段结束及之后定位到出点。右栏显示进入
      前的场景帧及循环序号。应用或取消后均恢复原场景播放头和片段选中。
- [x] 动作视图支持选中、新增、更新、移动和删除关键帧，提供视口控制器和精确数值输
      入。拖动先预览，点菱形写进会话，应用后作为一笔事务提交。同一片段的各次循环
      采样同一份编辑结果。
- [x] 复用 `poseMode/PoseModeRig.tsx` 的摆姿势交互，为会话提供动作时间与草稿写入
      目标。动作草稿保留原采样及骨骼通道，手动提交时写入选定骨骼在该时间的变换。
      与现有场景 `pose` 和左右手势属性分别保存。编辑库动作时创建可编辑副本。已有
      共享自建动作默认仅替换当前片段的引用，明确选择「全部引用」才影响其它片段。
- [x] 在片段级增加整数循环次数。设一个循环长度为动作出点减入点，总长度等于单循环
      长度乘次数。内部循环边界回到入点，普通片段结束时按现有相接规则接管。验证播
      放、倒拖和跳帧会得到同一姿势。可编辑预设使用原地步态，保留骨盆起伏及关节摆
      动。

**Mock 确认点**　打
开[五次走路循环](../specs/camera-studio-action-tracks-mock.html?demo=walk)，双击
「原地走路 ×5」。底部切换为动作时间轴，定位到局部第 8 帧。右栏显示场景第 73 帧和
第 3/5 次循环。选左前臂，调整角度，或拖动视口控制点并保留试摆。点菱形更新关键
帧，再点「应用并返回」，场景播放头回到第 73 帧。样稿用单根可编辑骨骼演示交互。

**验收**　走路从场景第 1 帧开始，每循环 32 帧，重复五次。修改动作局部第 8 帧，抽
查场景第 9、41、73、105、137 帧都呈现同一修改，并对照保存重开、播放和导出。检查
第 32–33 帧跨循环时的定位、片段结束边界及片段外进入的定位。核对库动作与其他副本
的引用，验证应用和取消都回到进入前的场景帧，并检查撤销。

## 第三步　角色路径绑定与导出

- [x] 参考 Blender 的 Follow Path，从角色属性选择已在场景中创建的独立路径。复用
      `CameraPath.tsx` 的曲线编辑和 `pathModel.ts` 的曲线构建。角色保存路径
      ID、`0–100%` 进度和「沿路径转向」设置。同一路径可供多个角色引用，各自打
      点、换绑或解绑。用归一化弧长映射求角色位置，使 50% 对应走过一半路程，线性
      进度对应匀速。开启转向时按水平切线和模型正前向求朝向。右栏显示当前进度对应
      的已走距离和总长。
- [x] 在统一求值入口应用路径约束。绑定后由路径驱动世界位置，开启转向时也由路径驱
      动世界朝向。原地动作提供迈步、摆臂和骨盆起伏。原位置关键帧保留并标明由路径
      接管，解绑后恢复原属性和对象动作的求值。路径缺失时预览恢复基础变换并显示修
      复入口，涉及该角色的导出给出资源错误。路径进度在首末关键帧外保持端点值。
- [x] 提交绑定或更换动作时，检测会随动作前进的根位移。以动作的角色根移动通道或素
      材标记为依据，保留骨盆和关节的局部起伏。遇到带前移的骨骼动作，提示具体片段
      并要求先改用原地版本。首版由用户选择或导入原地素材。遇到驱动同一变换组的对
      象动作，继续提示冲突组和时间区间。冲突时保留提交前的设置。
- [x] 将路径绑定、解除和进度打点接入撤销及项目保存。复用第一步的逐帧求值与导出流
      程，验证跟随机位在同一场景帧读取路径更新后的角色世界矩阵。

**Mock 确认点**　选中「白模角色」→「绑定路径」→ 选择「90° 圆弧」→「确认绑定」。
拖到进度 50%，时间轴路径行显示 50%，角色在圆弧中点沿切线迈步。解绑后在走路片段更
换为「走路（带前移）」再尝试绑定，核对提示能否帮助你回到片段改用原地走路。换绑直
线时保留原进度关键帧。

**验收**　同一工程包含直线版和 90°、半径 3.18 m 的圆弧版，各自完成五个步态循环。
以 30 fps、每循环 32 帧测试，抽查进度 0%、25%、50%、75% 和 100% 对应的弧长、半
径、切线朝向与姿势，确认末帧到达终点。保存重开后再次抽查这些帧，并对照拖动、正常
播放、导出与跟随机位。检查带前移片段触发绑定提示，换成原地动作可绑定，已绑定时更
换为带前移片段会保留当前动作。改变进度时序只改变行进速度，编辑摆臂只改变骨骼姿
势。自动步幅匹配和脚底锁定作为后续增量。
