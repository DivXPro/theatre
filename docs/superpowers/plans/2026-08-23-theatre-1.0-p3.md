# Theatre.js 1.0 P3 实施计划:协作最小闭环

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 两个浏览器经自托管 sync-server 实时同步(协作最小闭环,纯管道收口)。

**Architecture:** 给 studio 加一条「直连 ws 的自托管路径」——`serverUrl: 'ws://…'` 时跳过 app 解析与客户端 JWT 鉴权,直连 sync-server;sync-server 加 `AUTH_DISABLED` 让 `requireValidSession` 放行并在无 app 环境下独立启动(内存 SaazBack,无 Postgres 依赖)。现有 app-backed(http serverUrl)旧路径不动。补断线状态指示 + 两浏览器 e2e。

**Tech Stack:** tRPC v10(ws link)+ ws / saaz(BackMemoryAdapter)/ playwright e2e / tsx / zod / react(studio UI)。

**Spec:** `docs/superpowers/specs/2026-08-23-p3-collab-minimal-loop-design.md`(计划从 spec 立论;executor 需读 spec 全文)。

## Global Constraints

- 用户 WIP 文件不卷入 commit:`examples/*`、`.claude/`、`.ignore`、`.mcp.json`、`AGENTS.md`、`opencode.json`、`examples/dom-cra/src/react-app-env.d.ts`。**显式逐文件 `git add`,禁用 `git add -u`**(A1 裁定,沿用)。

- 直连 ws 模式 = **无鉴权**;app-backed http 旧路径(含 JWT)完整保留、不动。
- sync-server 的 SaazBack **保持内存**(BackMemoryAdapter);Postgres 持久化 = future work,不在本计划。
- studio 服务器连接设置入口 = `init({serverUrl})` + demo,**不建设置面板**(用户 2026-08-23 裁定)。

- [ ] **Step 3: 实现 `SyncServerLink`**

构造器加可选 DI 参数;新增轮询式连接状态(1s 轮询 `getConnection().readyState`,天然跨 tRPC 重连——每次重连都是新 WebSocket,轮询每次取当前 socket):

```ts
export type SyncServerConnectionState = 'connected' | 'reconnecting'

export default class SyncServerLink {
  private _client: CreateTRPCProxyClient<SyncServerRootRouter>
  private _wsClient: ReturnType<typeof createWSClient>

  constructor(
    private _url: string,
    opts: {createWSClientImpl?: typeof createWSClient} = {},
  ) {
    const createWSClientImpl = opts.createWSClientImpl ?? createWSClient
    const wsClient = createWSClientImpl({url: _url})
    this._wsClient = wsClient
    this._client = createTRPCProxyClient<SyncServerRootRouter>({/* 原逻辑不动 */})
    // …原 dev healthcheck 不动
  }

  onConnectionStateChange(
    cb: (state: SyncServerConnectionState) => void,
  ): () => void {
    const emit = () => {
      const ws = this._wsClient.getConnection()
      const state: SyncServerConnectionState =
        ws?.readyState === 1 ? 'connected' : 'reconnecting'
      cb(state)
    }
    emit()
    const iv = setInterval(emit, 1000)
    return () => clearInterval(iv)
  }

  get api() {
    return this._client
  }
}
```

```ts
import {test, expect} from '@playwright/test'
import {spawn} from 'child_process'
import * as path from 'path'
import * as http from 'http'
import * as net from 'net'

const MONOREPO_ROOT = path.resolve(__dirname, '..', '..', '..', '..', '..')

const findOpenPort = (): Promise<number> =>
  new Promise((resolve, reject) => {
    const srv = net.createServer()
    srv.unref()
    srv.on('error', reject)
    srv.listen(0, () => {
      const port = (srv.address() as net.AddressInfo).port
      srv.close(() => resolve(port))
    })
  })

const waitForServer = (port: number, timeoutMs = 20000): Promise<void> =>
  new Promise((resolve, reject) => {
    const start = Date.now()
    const poll = () => {
      const req = http.get({host: 'localhost', port, path: '/', timeout: 500}, (res) => {
        res.resume()
        if (res.statusCode === 200) return resolve()
        if (Date.now() - start > timeoutMs) return reject(new Error('sync-server not ready'))
        setTimeout(poll, 300)
      })
      req.on('error', () => {
        if (Date.now() - start > timeoutMs) return reject(new Error('sync-server not ready'))
        setTimeout(poll, 300)
      })
    }
    poll()
  })

test('two browsers sync via self-hosted sync-server', async ({browser}) => {
  const port = await findOpenPort()
  const server = spawn('yarn', ['exec', 'tsx', 'packages/sync-server/src/index.ts'], {
    cwd: MONOREPO_ROOT,
    env: {...process.env, PORT: String(port), HOST: 'localhost', AUTH_DISABLED: 'true'},
    stdio: ['ignore', 'pipe', 'pipe'],
  })
  server.stderr.on('data', (d) => process.stderr.write(`[sync-server] ${d}`))

  const ctxA = await browser.newContext()
  const ctxB = await browser.newContext()
  const pageA = await ctxA.newPage()
  const pageB = await ctxB.newPage()
  try {
    await waitForServer(port)
    const url = `./shared/sync/?serverUrl=ws://localhost:${port}`
    await pageA.goto(url)
    await pageB.goto(url)
    await expect(pageA.locator('#sync-value')).toHaveText('0')
    await expect(pageB.locator('#sync-value')).toHaveText('0')

    // 给 WS 订阅一个建立窗口
    await pageA.waitForTimeout(1000)

    // A 编辑
    await pageA.locator('#sync-plus').click()
    await expect(pageA.locator('#sync-value')).toHaveText('1')

    // B 实时收到(经 sync-server 推送)
    await expect(pageB.locator('#sync-value')).toHaveText('1', {timeout: 15000})
  } finally {
    server.kill('SIGTERM')
    await ctxA.close().catch(() => {})
    await ctxB.close().catch(() => {})
  }
})
```
