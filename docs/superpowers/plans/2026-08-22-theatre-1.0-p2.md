> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 1.0 公共 API 定稿(零新增)、0.7→1.0 状态迁移(格式 fixture 回归 + localStorage→IDB 迁移器)、持久化栈健壮性(9 个 final-review 遗留项 + spec 错误表),使 core/studio/saaz 达到 1.0 成色。

**Architecture:** 四条独立轨道,按依赖排序:
- **轨道 A — core API 定稿**:10 个 `__experimental_*` 逐个转正/合并(全部已有实现,无删除),`createContentOfSaveFile` stub 落地 + `OnDiskState` 类型定稿,`init()` 流程定稿,api-extractor 快照冻结公共 API。
- **轨道 B — 0.7 状态迁移**:第 1 层格式兼容回归(0.7 fixture 导入/导出链路);第 2 层介质迁移(localStorage `theatrejs:0.4` → saaz IDB,经 `diskSnapshot` 注入,只读不删)。
- **轨道 C — 持久化健壮性**:SaazBack save 序列化、IDB adapter close/teardown、会话锁 unlock、zombie unsub、updateChecker 死 UI、teardown 噪音、navigator.locks 测试、IDB 失败降级 + 内部状态 UI、backend 拒绝(spec:169 确定性回放失败)处理。
- **轨道 D — theatric 审查 + 辅助包核对**:theatric 补测试/评审 1.0 成色;r3f three/fiber 版本核对;改名一致性确认。

**Tech Stack:** TypeScript, yarn 3.6.3 workspaces, jest (jest-esbuild transform), fake-indexeddb, idb, @microsoft/api-extractor ^7.28.6, immer, saaz 同步引擎。

**Spec:** docs/superpowers/specs/2026-08-21-theatre-1.0-release-design.md

## Global Constraints

从 spec 逐字复制,所有任务隐式包含:

- npm scope = `@toy-box/*`;发布范围含 theatric,不含 app。
- 公共 API 可破坏(附迁移指南)。
- **单人模式核心原则(spec:162):任何持久化/迁移/网络错误都不能阻塞编辑本身——编辑永远可用,其余皆可降级。**
- 0.7 localStorage 数据**只读不删**(spec:155),迁移失败时旧数据保留。
- 状态兼容只保证项目状态(sheets/keyframes/objects,即 `createContentOfSaveFile` 的 JSON);studio UI 布局状态不迁移,升级后重置为默认(spec:158)。
- **P2 零新增公共 API**。D1(迁移失败恢复导出函数)、D2(`studio.persistenceStatus`)已代码层核实为 UI 方案覆盖,不建公共 API——本计划的内部状态(ephemeralAtom.persistenceStatus)与既有 `getProject(id, {state})` 即可覆盖。
- 版本约束:r3f peer `three >= 0.155.0`、`@react-three/fiber ^8.13.6`(已与 compat-tests fixtures 对齐,不改)。
- 测试约束(本 fork 实证):
  - jest-esbuild **不提升 `jest.mock`**——mock 模块必须用 `jest.doMock` + `jest.resetModules()` + 运行时 `require(...)`(含传递依赖)。
  - fake-indexeddb 对无效 IDB key 静默宽容,真实 IDB 抛 `DataError`——IDB adapter 层必须按对象存储的 `keyPath` 传键;IDB 改动要补行为回归测试 + 尽量用 Playwright/真实浏览器验证。
- 所有 implementer 禁止 `git add -A`(会卷入用户未跟踪的 `.claude/`、`opencode.json` 等);一律 `git add -u` + 显式新文件路径。

- [ ] **Step 3: 实现 StudioStore.createContentOfSaveFile**

```ts
// StudioStore.ts, 替换 217 行的 stub
createContentOfSaveFile(projectId: ProjectId): OnDiskState {
  const projectState = this._saaz.state.op.historic.coreByProject[projectId]
  if (!projectState) {
    throw new Error(`Project ${projectId} has not been initialized.`)
  }
  const revision = generateDiskStateRevision()
  this.tempTransaction(({stateEditors}) => {
    stateEditors.coreByProject.historic.revisionHistory.add({
      projectId,
      revision,
    })
  }).commit()
  return {
    ...projectState,
    revisionHistory: [revision, ...projectState.revisionHistory],
  }
}
```

> 路径已核实:saaz `op` = `StudioState`(schema.ts:94 `initialState` 形状 `{$schemaVersion, ahistoric, historic, ephemeral}`),`historic.coreByProject[projectId]` **直接就是** `ProjectState_Historic`(含顶层 `revisionHistory`——`setProjectState`(schema.ts:761)把它 `cloneDeep` 整存;`initialiseProjectState` 直接读它的 `revisionHistory`)。`tempTransaction(...).commit()` 是否存在以当前 StudioStore 源码为准(若无,改走 `this._saaz.commit()` 或现有事务入口——用 graft/grep 找 StudioStore 里既有的临时事务调用点)。

`packages/studio/src/StudioStore/migrateFromLocalStorage.ts`:

```ts
export const LEGACY_LOCAL_STORAGE_KEY = 'theatrejs:0.4'

export type LegacyMigrationResult =
  | {found: false}
  | {
      found: true
      projects: Record<string, OnDiskState> // 通过校验的项目
      failedProjectIds: string[] // 解析出但校验失败的项目 id
    }

/** 只读解析 0.7 localStorage blob。绝不写入/删除 localStorage。 */
export function parseLegacyBlob(raw: string): {
  projects: Record<string, unknown>
  wrapperDetected: boolean
} {
  const parsed = JSON.parse(raw)
  // 接受 {version, projects} 或 {projects};也接受裸 {[projectId]: state}
  const projects =
    parsed && typeof parsed === 'object' && 'projects' in parsed
      ? parsed.projects
      : parsed
  if (!projects || typeof projects !== 'object') {
    throw new Error('Legacy blob has no projects map')
  }
  return {projects, wrapperDetected: 'projects' in parsed}
}

export function readLegacyLocalStorageState(): LegacyMigrationResult {
  try {
    const raw = window.localStorage.getItem(LEGACY_LOCAL_STORAGE_KEY)
    if (!raw) return {found: false}
    const {projects} = parseLegacyBlob(raw)
    const validated: Record<string, OnDiskState> = {}
    const failedProjectIds: string[] = []
    for (const [projectId, state] of Object.entries(projects)) {
      try {
        shallowValidateOnDiskState(projectId, state as OnDiskState)
        validated[projectId] = state as OnDiskState
      } catch {
        failedProjectIds.push(projectId)
      }
    }
    return {found: true, projects: validated, failedProjectIds}
  } catch (e) {
    // JSON 解析失败/结构异常 → 视为整体失败,保留原始数据不动
    return {found: true, projects: {}, failedProjectIds: []}
  }
}
```
