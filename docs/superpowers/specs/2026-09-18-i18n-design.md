# i18n 方案设计(studio 可嵌入词典 + 宿主扩展)

日期:2026-09-18
状态:已确认实施(自研轻量方案)

## 目标

- studio UI 文案可翻译、可切换语言
- **宿主应用可注入自己的词典**:补新语言、覆盖 studio 内置词条(品牌定制)
- 不引入运行时依赖,不绑架宿主的技术栈(宿主可能已有自己的 i18n)
- camera playground(中文文案)作为第一个全量接入方,验证"其他应用植入"路径

## 非目标(v1)

- 复数规则/ICU MessageFormat(词条以单数形式写;需要时后续加 formatter 钩子)
- 数字/日期本地化
- studio 全部文案一次性收编(机制先行,剩余文案机械收编)

## 架构

### 核心模块 `packages/studio/src/i18n/`

```
i18n/
  core.ts      纯逻辑,零依赖零 React:注册表、回退链、语言决策、t()
  react.tsx    I18nProvider / useT() / useLanguage()(响应式重渲染)
  dicts/
    en.ts      studio 内置词条(基准语言,key 的权威定义)
    zh-CN.ts   studio 内置中文词条
  index.ts     公共导出
```

**核心是一个模块级单例**。studio 与宿主应用 import 同一个包即共享同一
实例,宿主不必传任何 provider。

### 词典与合并

- 词典是平铺的点分键对象:`{'outline.title': '大纲', ...}`
- `registerMessages(lang, messages)`:按键深合并,**后注册覆盖先注册**——
  宿主后注册即可覆盖 studio 内置词条
- 语言回退链:`registerFallback('zh-TW', 'zh-CN')`;t() 查找顺序
  当前语言 → 沿回退链逐级 → 返回 key 原文(永远有输出,永不抛错)

### 语言决策优先级

1. 宿主显式指定(`IExtension.i18n.language` 或 `studio.i18n.setLanguage`)
2. 用户上次选择(localStorage 持久化,`theatre-i18n-language`)
3. 浏览器语言(navigator.language 前缀匹配注册语言,沿回退链)
4. 回退 `'en'`

用户手动 setLanguage 会写入 localStorage;宿主显式指定(language 选项)
**不**写 localStorage(那是会话级强制,不劫持用户偏好)。

### 宿主接入 API

```ts
// 方式一:扩展点(推荐,和 toolbars/panes 同级)
studio.extend({
  id: 'my-app',
  i18n: {
    language: 'zh-CN',                       // 强制初始语言(最高优先级)
    messages: {'zh-CN': {'outline.title': '场景树'},  // 补语言/覆盖词条
    fallbacks: {'zh-HK': 'zh-CN'},
  },
})

// 方式二:命令式
studio.i18n.registerMessages('ja', {...})
studio.i18n.setLanguage('ja')
```

`IStudio` 新增 `i18n` 命名空间:`t(key, vars?)` / `getLanguage()` /
`setLanguage(lang)` / `registerMessages(lang, messages)` /
`registerFallback(from, to)` / `onLanguageChange(fn)`。

### 插值

`t('export.count', {count: 3})` → `'导出 3 个文件'`(`{var}` 占位)。
值可以是 string/number。

### React 绑定

studio 自己持有 React root:provider 挂在 UIRoot,组件用
`const t = useT()`;语言切换 → context value 变化 → 订阅组件重渲染。
非 React 宿主(纯命令式调 `studio.i18n.t`)也能用。

### camera playground 接入

`packages/playground/src/shared/camera/i18n.ts` 注册 en/zh-CN 两份
词典(顶栏 tooltip、资产库、菜单、提示条全部中文字符串收编),
组件内 `useT()` 替换硬编码中文。菜单构建函数(menuModel)的文案在
调用处传 `t` 进去,保证语言切换后菜单重建。
